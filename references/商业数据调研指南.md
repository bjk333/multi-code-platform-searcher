# 商业 / 市场 / 融资数据调研指南（WebSearch 互补环节）

> 配套 multi-code-platform-searcher：技能做「代码/仓库/学术/包」结构召回；**商业数据（市场/融资/定价/竞品财务）走本指南 + WebSearch**。
> 背景：Crunchbase 官方 API 免费 tier 已取消（2025 起），国内商业库全付费——无免费稳定 API 可接入技能，故以"免费渠道清单 + 信号转译"补足。

## 一、免费可查渠道清单

| 数据需求 | 免费渠道 | 说明 |
|---|---|---|
| 公司/融资（海外） | Crunchbase 网页（`crunchbase.com/organization/<slug>`） | React SPA，浏览器查看；手动复制关键字段 |
| 公司/融资（国内） | IT桔子（itjuzi.com）、企查查/天眼查网页端（登录免费额度） | 网页检索公司/融资/股东 |
| 定价 | 官网 pricing 页 + WebSearch `site:官网 pricing` | 直接查产品页 |
| 市场/行业报告 | 艾瑞、亿欧、IDC、Gartner 摘要、36氪、动脉网 | WebSearch `行业报告 2026 关键词` |
| 融资新闻 | 36氪、IT桔子日报、TechCrunch、YC 数据库 | WebSearch `关键词 融资 轮次` |
| 招聘信号 | 官网 careers、脉脉/领英、招聘平台 | "扩招 = 增长信号" |
| 政策法规 | 网信办、信安标委、工信部官网 | WebSearch `site:官网 关键词` |

## 二、技能 + 指南分工（v3.0 方法论）

```
multi-code-platform-searcher（结构召回）
  仓库发现 → 竞品/生态项目
  代码证据 → 实现细节/配置示例
  研究信源 → 学术/包/模型/问答/MCP
        ↓ 商业数据
本指南 + WebSearch（语义查证）
  融资/定价/市场 → 免费渠道 + site: 定向
  用户反馈 → HN/Reddit/中文社区 site: 查询
  政策 → 监管官网
```

## 三、信号转译（把商业信息变成技能可检索信号）

| 商业事实 | 转译为可检索信号 |
|---|---|
| "某公司获融资/扩招" | 技能搜该公司 GitHub 仓库 star 增长 / 技术栈仓库 |
| "某领域火了" | 技能 `-ResearchSources` 搜该领域（HF 模型数/包下载量/arXiv 论文数 = 热度代理） |
| "竞品闭源" | 技能搜竞品名仓库（GitHub 组织页）+ 文档代码证据 |
| "市场规模" | WebSearch 行业报告 + 技能搜头部玩家仓库规模（stars/commits 近似活跃度） |

## 四、落地步骤

1. 先 `-Doctor` 确认引擎健康 → 技能跑三模式（仓库/代码/研究）拿结构证据
2. 商业数据缺口 → 本指南渠道 + WebSearch `site:` 定向
3. 交叉印证：技能命中 + 商业数据 + 官方文档三源一致才下结论
