# 数据与隐私（外发范围 · 本地留存 · 令牌）

> **一句话**：技能在你的机器上运行。离开本机的只有**检索词、过滤条件、仓库/包坐标**；没有遥测，没有自建上报服务。
> 本文件的域名清单由门 U-238 从 `engines/*.ps1` 与主脚本**枚举后比对** —— 新增引擎不登记会红，不靠人记。

## 1. 外发什么、不外发什么

| 你的输入 | 是否离开本机 | 说明 |
|---|---|---|
| `-Keyword` | **是** | 作为查询参数发给被选中的引擎；`-Auto` 下 repo/code 用**改写后的短词**（改写规则见 `参数速查.md`） |
| `-Language` / `-MinStars` / `-ActiveWithin` / `-License` / `-PathFilter` | **是** | 作为过滤参数随请求发送 |
| `-Package "生态:包名"` | **是** | 精确包元数据查 deps.dev |
| `-RepoScope owner/repo` | **是** | 仓库坐标（GitLab 项目级 blobs / searchcode） |
| `-LocalPath` 下的**文件内容** | **否** | rg / ugrep / ast-grep 本地执行；结果只回本机 |
| 检索结果、报告、`-OutFile` / `--out` 文件 | **否** | 只写本机 |
| 令牌（见 §3） | **是（仅请求头）** | 不写缓存、不进日志、不出现在任何输出 |

**`-Doctor` 是一个例外，必须说清**：它会对每个研究源各发一次**轻量探活**，查询词是固定的占位串 `__mcps_probe__`（不是你的查询词）；另外用 `GITHUB_TOKEN` / `GITLAB_TOKEN` 各请求一次 `/user` 校验凭据（只验身份，不读数据）。`DeepSeek` **不会**为了验 key 发请求（Search 端点成功即计费，Doctor 记 `Probe=skipped`），失败留到真实检索时上报。不跑 `-Doctor` 就不会发这些请求。

## 3. 令牌

- 读取来源只有两个：**环境变量**，或技能目录下的 `.env`（**键白名单**，未列入的键不会被设进进程环境）。
- 支持：`GITHUB_TOKEN`、`GITLAB_TOKEN`、`GITEE_TOKEN`、`SRC_TOKEN`、`SOURCEGRAPH_TOKEN`、`SE_KEY`、`DEEPSEEK_API_KEY`、`S2_API_KEY`、`GLAMA_API_KEY`。
- 发送方式**只有请求头**：`Authorization: token|Bearer …`、`PRIVATE-TOKEN`、`x-api-key` 或查询参数 `key=`（Stack Exchange 官方要求）。**不放在 URL 路径、不写文件、不打印。**
- `-Doctor` 只输出 `Present` / `Valid`（及探测结论），**从不输出令牌值**。
- 令牌缺失或失效 ⇒ 对应源记为 `blocked` 并写明原因（`coverage` / `reasons` 可见），**不会静默降级**。

## 4. 本地留存

| 位置 | 内容 | 控制方式 |
|---|---|---|
| `<技能目录>/search_cache.json` | 查询键 + 结果对象（**不含令牌、不含请求头**），默认 TTL 900 秒 | `MCPS_CACHE_FILE=<路径>` 改位置；`-NoCache` **只跳过读取、仍写入本轮结果**（刷新语义）——要完全不落盘，把 `MCPS_CACHE_FILE` 指到临时目录或事后删除该文件 |
| `<当前工作目录>/downloads/<repo>_<时间戳>/` | `-Download` 拉取的源码 zip 与解压内容 | 只在你显式 `-Download` 时产生；目标已存在不覆盖，落到新时间戳目录 |
| 控制台输出 / `-OutFile` / `--out` | 结果 JSON 或人读摘要 | 由你的终端与宿主决定是否留存；技能本身不写额外日志文件 |

## 5. 第三方计费

- **DeepSeek 网页搜索是第三方付费服务**（DeepSeek 官方 Search API），**按成功请求计费**，使用**你自己的** `DEEPSEEK_API_KEY`，费用由你的账号承担。
- 未配置 `DEEPSEEK_API_KEY` ⇒ 该源**整体不进 `Requested`**，不影响既有源的 `Verdict`。
- 其余源当前为公开/匿名配额（如 GitHub 匿名 10 次/分，带令牌 30 次/分）；配额与条款归各源运营方，可能变化。

## 6. 代理与网络

- 默认 `-ProxyMode auto`：按本次真实请求 URL 逐域短探活，在 `MCPS_PROXY` 白名单 → 进程代理 → 系统代理 → 直连之间选择。
- 如宿主只允许直连，用 `-ProxyMode direct`（不要盲清代理环境变量）。
- TLS/DNS 由 .NET 请求栈处理；不额外引入第三方 SDK 或统计库。

## 7. 收窄与关闭

| 目的 | 做法 |
|---|---|
| 只打一个源 | `-Platform GitHub` |
| 关掉指定引擎 | `MCPS_DISABLE=GitLab,DeepSeek`（CLI 与 MCP/Serve 都生效） |
| 不查研究源 | 不加 `-ResearchSources`；不用 `-Auto`（planner 可能选 research 池） |
| 不查代码 | 不加 `-CodeEvidence`；不用 `-Auto`（planner 可能选 code 池）；或用 `MCPS_DISABLE` 关掉 code 引擎 |
| **零外发（需显式禁用远程）** | `-LocalCodeSearch -LocalPath <目录>` **加上** `MCPS_DISABLE=GitHubCode,GitLabBlobs,GrepApp,SEExcerpts,Sourcegraph`。⚠️ 只加 `-LocalCodeSearch` **不等于零外发**：本地 0 命中会按设计**自动降级远程 code 引擎**（发请求，并在 `warnings[]` 留痕） |
| 强制直连 | `-ProxyMode direct` |

## 8. 明确不做的事

- **不上传**本地文件内容、仓库内容或检索结果到任何服务。
- **不做遥测**：没有使用统计、没有崩溃上报、没有自建收集端点。
- **不把令牌写进**缓存、日志、错误消息或 JSON 输出。
- **不代你调用**任何需要付费的源（DeepSeek 只在你自己配 key 后才会被请求）。
- **不隐藏降级**：哪个源没查成、为什么，写在 `coverage` / `warnings[]` / `reasons` 里。
